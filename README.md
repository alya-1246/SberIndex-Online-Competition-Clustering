# Sber Consumer Clustering

Анализ потребительского поведения и доходов населения на уровне муниципальных образований (МО) за 2023–2024 гг. с кластеризацией территорий по структуре расходов.

---

## Цель

Сравнить потребительские профили территорий за два года, выделить устойчивые группы и предложить бизнес-интерпретацию кластеров.

---

## Данные

| Файл | Содержание |
|------|-----------|
| `consumption.csv` | Потребительские безналичные расходы по категориям |
| `market_access.csv` | Индекс доступности рынков |
| `bdmo_population.csv` | Население по возрастным группам |
| `bdmo_migration.csv` | Миграция |
| `bdmo_salary.csv` | Заработная плата по отраслям |

**Категории расходов:** здоровье, маркетплейсы, общественное питание, продовольствие, транспорт.

---

## Предобработка

1. **Население** — удалены агрегаты «Всего», возраст приведён к числу, сгруппирован в 4 когорты (`до 18`, `18–45`, `46–64`, `от 65`), развёрнут в wide-формат по `territory_id`.
2. **Зарплаты** — фильтр «январь-декабрь» + «Все отрасли», агрегация по территории.
3. **Расходы** — исключены строки «Все категории», агрегация и разворот отдельно за 2023 и 2024.
4. **Объединение** — inner join по `territory_id`, удаление пропусков.
5. **Нормирование** — z-оценки (`scale()`) перед кластеризацией.

---

## Методы

### Иерархическая кластеризация
Матрицы расстояний: евклидово, манхэттенское, Чебышёва, Минковского (p = 3).  
Методы объединения: **Уорда (ward.D)** и **средних (average)**.

### K-means
Перебор `k = 2…10`, `nstart = 25`. Оптимум определялся по:
- методу «локтя» (WSS),
- статистике разрыва `clusGap` (B = 100),
- среднему силуэту `silhouette()`,
- индексу Дэвиса–Болдина `index.DB()`,
- доле объяснённой дисперсии `betweenss / totss`.

### DBSCAN
Параметры `eps` подобраны по `kNNdistplot` (k = 3 и 5), `minPts = 3`.

---

## Результаты

### 2023 год
| Метрика | Лучший вариант |
|---------|----------------|
| Силуэт | k = 3 (~0.33–0.40) |
| Дэвис–Болдин | k = 3 (~1.10) |
| Объяснённая дисперсия | ~50 % |

**Кластеры:**
- аномально высокая доля продовольствия (n = 5, 5 %),
- развитое сервисное потребление (n = 29, 29 %),
- средний профиль (n = 66, 66 %).

DBSCAN (eps = 6.5, minPts = 5) выделил один кластер — данные не образуют плотностных сгущений.

### 2024 год
| Метрика | Лучший вариант |
|---------|----------------|
| Силуэт | k = 4 (0.46) |
| Дэвис–Болдин | k = 4 (0.88) |
| Объяснённая дисперсия | 70 % (k = 4) / 76 % (k = 5) |

**Кластеры:**
1. Минимальный доход и потребление (зарплата −2.09, продовольствие −2.66).
2. Повышенный доход и активность (зарплата +0.79, общепит +1.22).
3. Средний уровень.
4. Умеренный доход, слабые digital-категории (маркетплейсы −0.64).
5. Низкий доход + активность в маркетплейсах/общепите (n = 5).

---

## Выводы

- 2023: устойчивая структура из **3 кластеров**, умеренное качество (силуэт ~0.33).
- 2024: структура стала **более выраженной** — оптимум 4 кластера, силуэт 0.46, объяснённая дисперсия 70 %.
- DBSCAN подтвердил «облачную» природу данных — K-means обоснован.
- Наблюдается **усиление дифференциации** территорий по доходу и расходам.

---

## Бизнес-применение

| Кластер | Рекомендация |
|---------|--------------|
| Повышенный доход | Программы лояльности, кросс-продажи, премиум-предложения |
| Умеренный доход | Массовые акции, стимулирование маркетплейсов и общепита |
| Низкий доход / аномальные | Реактивационные кампании, целевые акции на маркетплейсах и в сфере здоровья |

## Ограничения

- Кластеризация на первых 100 строках выборки.
- DBSCAN требует более тонкой настройки `eps`.
- Нет проверки устойчивости кластеров (bootstrap, сравнение разбиений по годам).
- `market_access.csv` загружен, но в кластеризации не использован.
